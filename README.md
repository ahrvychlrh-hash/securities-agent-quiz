# 투자권유대행인 문제풀이

증권투자권유대행인 자격시험을 틈틈이 휴대폰으로 공부하는 웹 서비스입니다.
빌드 과정 없는 정적 웹앱(HTML/CSS/JS)입니다.

## 실행

```bash
node serve.js
```

- PC: http://localhost:5173
- 휴대폰(같은 Wi-Fi): 서버가 출력하는 `http://<PC IP>:5173` 주소로 접속합니다.
- 언제 어디서나 쓰려면 이 폴더를 GitHub Pages나 Netlify 같은 정적 호스팅에 그대로 올리면 됩니다.

## 핵심 구조: 문제가 아니라 "개념"을 저장

`js/data.js`의 항목 하나는 핵심 부분을 `{}`로 비워 둔 문장입니다.

```js
{ id: 'm01', s: 1, t: '유가증권시장',
  q: '유가증권시장과 코스닥시장의 일일 가격제한폭은 기준가격 대비 상하 {}이다.',
  a: '30%',                       // 정답
  w: ['10%', '15%', '20%'],       // 넣으면 틀린 문장이 되는 값
  e: '해설…' }
```

엔진(`js/engine.js`)은 이 한 문장으로 매번 다른 문제를 만듭니다.

| 유형 | 만드는 방법 |
|---|---|
| 빈칸 채우기 | `{}`를 비우고 정답과 오답 후보를 섞어 보기로 냄 |
| O / X | 정답 또는 오답 후보를 무작위로 넣어 참·거짓 문장을 만듦 |
| 옳은 것 / 옳지 않은 것 | 같은 과목의 다른 개념 3개와 섞어 4지선다를 만듦 |
| 모두 고르기 (ㄱ~ㄹ) | 문장 4개의 참·거짓을 매번 새로 정하고 조합 보기를 만듦 |
| 계산형 | `CALCS`의 `gen()`이 매번 새 숫자로 문제를 만듦 (PER, PBR, ROE, 고든모형, 유동비율, 할인채, 샤프지수, CAPM) |

모든 유형에서 정답·오답과 상관없이 바르게 고친 문장, 보기별 판정, 풀이, 해설을 보여 줍니다.

## 화면 흐름

홈 → 과목별 챕터(세부과목) 선택 → **개념 공부**(설명만 읽기) 또는 **문제 풀기**

- 개념 공부: 핵심 문장(바뀌어 나오는 부분 강조), 자주 나오는 오답 보기, 해설, 계산 예제
- 문제 풀기: 챕터 개념으로 최대 10문제. 개념이 5개 미만이면 같은 개념을 다른 유형으로 반복해 5문제를 채움
- 결과: 정답률을 과락선(40%)·합격선(60%)과 비교하고 실제 시험 문항 수로 환산

## AI 튜터 (해설에 대해 질문하기)

문제를 풀고 해설이 나오면 그 아래에서 AI에게 질문할 수 있습니다.
방금 푼 문제, 보기, 내가 고른 답, 정답, 해설이 함께 전달되어 그 문제에 맞춰 답합니다.

- **웹사이트 · 로컬: 제미나이** (`js/gemini.js`)
  - 설정(톱니바퀴)에서 [Google AI Studio](https://aistudio.google.com/apikey)에서 받은 무료 API 키를 입력합니다.
  - 키는 그 기기 브라우저에만 저장되고, 요청 헤더(`x-goog-api-key`)로만 보냅니다. 코드에는 키가 없습니다.
  - 키로 모델 목록을 받아 Flash-Lite → Flash 순으로 자동 선택합니다. 설정에서 바꿀 수 있습니다.
- **claude.ai Artifact: Claude** (`claude-artifact.html`, `sample` 기능)
  - 내 Claude 계정 사용량을 씁니다. claude.ai에서는 외부 서비스 연결이 막혀 제미나이를 쓸 수 없습니다.

## 웹사이트로 배포 (GitHub Pages)

빌드가 필요 없는 정적 파일이라 폴더를 그대로 올리면 됩니다. `index.html`이 첫 화면입니다.

## 합격 기준

과목별 정답률 40% 이상(과락 면제)이면서 전체 정답률 60%(60문항) 이상.
과락은 챕터가 아니라 과목 단위로 판정합니다. 1과목 12/30, 2과목 20/50, 3과목 8/20문항 이상이 필요합니다.
기준값은 `js/data.js`의 `PASS`, 챕터별 출제 문항 수는 `CHAPTERS`에 있습니다.

## 학습 기록

- 브라우저 `localStorage`(이 기기)에만 저장됩니다.
- 틀린 개념은 오답노트에 들어가고, 다른 유형으로 **연속 2번** 맞히면 빠집니다.
- 처음 보는 개념과 오답노트 개념이 더 자주 출제됩니다.

## 개념 추가하기

`js/data.js`의 `FACTS` 배열에 같은 형식으로 추가하면 바로 모든 유형으로 출제됩니다.
`w`가 1개뿐이면 빈칸 문제는 2지선다가 됩니다. 3개 이상을 권장합니다.
