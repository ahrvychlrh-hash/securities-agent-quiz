# 꿈디 — 꿈을 디자인하다

증권투자권유대행인 · 펀드투자권유대행인 · 투자자산운용사 시험을 틈틈이 휴대폰으로 공부하는 웹 서비스입니다.
빌드 과정 없는 정적 웹앱(HTML/CSS/JS)입니다.

## 실행

```bash
node serve.js
```

- PC: http://localhost:5173
- 휴대폰(같은 Wi-Fi): 서버가 출력하는 `http://<PC IP>:5173` 주소로 접속합니다.

## 화면 흐름

홈(캐릭터 · 자격증 선택 · 올해 남은 시험 일정) → 자격증 홈(과목·챕터, 합격 기준) → 챕터 → **개념 공부** 또는 **문제 풀기**

- 개념 공부: 핵심 문장(바뀌어 나오는 부분 강조), 자주 나오는 오답 보기, 해설, 계산 예제
- 문제 풀기: 챕터 개념으로 최대 10문제. 개념이 5개 미만이면 같은 개념을 다른 유형으로 반복해 5문제를 채움
- 결과: 정답률을 그 자격증의 과락선·합격선과 비교하고 실제 시험 문항 수로 환산
- 시험 일정: `js/certs.js`의 `schedule`에서 오늘 이후 시험만 날짜순으로 보여 주고 D-day·접수 상태를 계산

## 주요 기능

- **실전 모의고사**: 챕터별 실제 출제 문항 수대로 100문항, 시험시간 타이머(시간 종료 시 자동 제출), 문항표로 이동, 제출 후 과목별 과락·합격 판정과 문제별 해설
- **오늘의 목표 · 연속 학습일**: 하루 목표(설정에서 5~50문제)와 연속 학습일, 최근 7일 기록
- **오답노트 AI 정리**: 틀린 개념을 모아 자주 틀리는 주제·헷갈리는 개념·외우는 팁·다음 공부 순서를 AI가 정리
- **오프라인 사용**: `sw.js`(서비스 워커)가 앱 파일을 저장해 인터넷 없이도 열림. 새 버전은 다음에 열 때 반영. 앱 파일 목록이 바뀌면 `sw.js`의 `VERSION`과 `CORE`를 갱신

## 핵심 구조: 문제가 아니라 "개념"을 저장

개념 하나는 핵심 부분을 `{}`로 비워 둔 문장입니다.

```js
{ id: 'm01',
  q: '유가증권시장과 코스닥시장의 일일 가격제한폭은 기준가격 대비 상하 {}이다.',
  a: '30%',                       // 정답
  w: ['10%', '15%', '20%'],       // 넣으면 틀린 문장이 되는 값
  e: '해설…' }
```

| 파일 | 내용 |
|---|---|
| `js/data.js` | 증권투자권유대행인 개념·계산형 (공통 개념 포함) |
| `js/data-more.js` | 펀드투자권유대행인·투자자산운용사용 추가 개념·계산형 |
| `js/certs.js` | 자격증별 과목·챕터·합격 기준·시험 일정. 챕터마다 개념 id를 골라 붙임 |
| `js/lessons.js` | 챕터별 개념 정리 본문(정의·공식·표·시험 포인트). `==글자==`는 자주 출제 밑줄 |
| `js/engine.js` | 개념 한 문장으로 문제를 만드는 엔진 |

같은 개념을 여러 자격증이 함께 쓰므로(예: 직무윤리, 금소법) 한 곳에서 고치면 모두 반영되고 학습 기록도 공유됩니다.

### 출제 유형 (실제 시험과 같은 객관식 4지선다만)

| 유형 | 만드는 방법 |
|---|---|
| 옳은 것 / 옳지 않은 것 | 같은 과목의 다른 개념 3개와 섞어 4지선다를 만듦 |
| 모두 고르기 (ㄱ~ㄹ) | 문장 4개의 참·거짓을 매번 새로 정하고 조합 보기를 만듦 |
| 빈칸에 알맞은 것 | 오답 후보가 3개 이상인 개념만, 정답과 섞어 4지선다로 냄 |
| 계산형 | `gen()`이 매번 새 숫자로 문제를 만듦 (PER, PBR, ROE, 고든모형, 유동비율, 할인채, 샤프지수, CAPM, 직접환원법, VaR, 수정듀레이션) |

모든 유형에서 정답·오답과 상관없이 바르게 고친 문장, 보기별 판정, 풀이, 해설을 보여 줍니다.

## 자격증별 구성 (총 100문항)

| 자격증 | 과목 (문항) | 합격 기준 |
|---|---|---|
| 증권투자권유대행인 | 증권분석 및 증권시장 30 · 금융상품 및 윤리 50 · 법규 및 규정 20 | 전체 60% · 과목별 40% |
| 펀드투자권유대행인 | 투자권유 50 · 펀드투자 30 · 부동산펀드 20 | 전체 60% · 과목별 40% |
| 투자자산운용사 | 금융상품 및 세제 20 · 투자운용 및 전략Ⅱ·투자분석 30 · 직무윤리·법규 및 투자운용 및 전략Ⅰ 50 | 전체 70% · 과목별 40% |

과락은 챕터가 아니라 과목 단위로 판정합니다. 시험 구성·일정은 교육업체가 옮긴 금융투자협회 안내를 기준으로 했으므로 접수 전 [금융투자협회 자격시험센터](https://license.kofia.or.kr)에서 확인하세요.

## AI 튜터 (해설에 대해 질문하기)

문제를 풀고 해설이 나오면 그 아래에서 AI에게 질문할 수 있습니다.
방금 푼 문제, 보기, 내가 고른 답, 정답, 해설이 함께 전달되어 그 문제에 맞춰 답합니다.

- **웹사이트 · 로컬: 제미나이** (`js/gemini.js`)
  - 설정(톱니바퀴)에서 [Google AI Studio](https://aistudio.google.com/apikey)에서 받은 무료 API 키를 입력합니다.
  - 키는 그 기기 브라우저에만 저장되고, 요청 헤더(`x-goog-api-key`)로만 보냅니다. 코드에는 키가 없습니다.
  - 키로 모델 목록을 받아 Flash-Lite → Flash 순으로 자동 선택합니다. 설정에서 바꿀 수 있습니다.
- **claude.ai Artifact: Claude** (`claude-artifact.html`, `sample` 기능)
  - 내 Claude 계정 사용량을 씁니다. claude.ai에서는 외부 서비스 연결이 막혀 제미나이를 쓸 수 없습니다.

## 개념 추가하기

1. `js/data.js` 또는 `js/data-more.js`에 같은 형식으로 개념을 추가합니다. `w`(오답 후보)는 3개 이상을 권장합니다.
2. `js/certs.js`에서 원하는 자격증 챕터의 `ids`에 그 개념의 `id`를 넣습니다.

> 문제 내용은 학습 보조용입니다. 법령·제도는 바뀔 수 있으므로 최신 금융투자협회 기본서와 함께 확인하세요.
